# 投稿に付ける画像の置き場所

オーナーがAI画像ツールなどで作った画像を、このフォルダに入れてください。

**2026-09-25 オーナー決定: 毎回自動で使う機能ではなく、「いつ・どの投稿に使うか」を1回ごとに指定する運用にした。**
`data/research-settings.json` の `oneTimeOwnImage`(例: `{ "date": "2026-09-25", "hour": 20 }`)に書いた日付・時刻(JST)の投稿1件だけ、このフォルダの画像からランダムに1枚付く。その時刻を過ぎると自動的に効かなくなる(消し忘れの心配なし)。次に使いたいときは、この日付・時刻を書き換える。

- 対象になるのは早見表以外の投稿(19:00・20:00・21:00の枠)のみ
- ファイルの形式: `.jpg` `.jpeg` `.png` のみ(それ以外は無視されます)
- 大きさ: 1枚 8MB 以下。縦長(1080×1350)か正方形(1080×1080)がおすすめ
- 指定した投稿の直前に使った画像がある場合、続けて同じ画像は使わないようにしてあります(2枚以上あるとき)
- `oneTimeOwnImage` の日時に当てはまらない投稿は、今までどおりの動き(おすすめ投稿の画像 → 商品画像)になります
- 入れたあと、ほにょがGitHubへ反映すると指定した投稿から使われます
- 使わせたくなくなった画像は、ファイルを消すか、フォルダの外へ移してください
