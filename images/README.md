# 投稿に付ける画像の置き場所

オーナーがAI画像ツールなどで作った画像を、このフォルダに入れてください。

**2026-09-25 オーナー決定: 毎回自動で使う機能ではなく、「いつ・どの投稿に使うか」を1回ごとに指定する運用にした。**
`data/research-settings.json` の `oneTimeOwnImage` は配列で、1件ごとに「日付・時刻(JST)・(任意で)使うファイル名」を書く。例:
```json
"oneTimeOwnImage": [
  { "date": "2026-09-25", "hour": 20 },
  { "date": "2026-09-25", "hour": 21, "file": "70330.jpg" }
]
```
`file` を書かなければ、このフォルダの画像からランダムに1枚(直前と同じものは避ける)。`file` を書けば、必ずそのファイルだけを使う — フォルダの中に他の投稿用の画像が混ざっていても、指定した投稿には指定した画像しか付かない。それぞれの時刻を過ぎると自動的に効かなくなる(消し忘れの心配なし)。次に使いたいときは、配列に新しい項目を足すか、日付・時刻を書き換える。

- 対象になるのは早見表以外の投稿(19:00・20:00・21:00の枠)のみ
- ファイルの形式: `.jpg` `.jpeg` `.png` のみ(それ以外は無視されます)
- 大きさ: 1枚 8MB 以下。縦長(1080×1350)か正方形(1080×1080)がおすすめ
- `oneTimeOwnImage` のどの日時にも当てはまらない投稿は、今までどおりの動き(おすすめ投稿の画像 → 商品画像)になります
- 入れたあと、ほにょがGitHubへ反映すると指定した投稿から使われます
- 使わせたくなくなった画像は、ファイルを消すか、フォルダの外へ移してください(他の`oneTimeOwnImage`から`file`で参照されていないことを確認してから)
